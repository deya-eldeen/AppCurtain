# AppCurtain Example

This folder contains a small SwiftUI app that shows how to initialize
AppCurtain. Use XcodeGen to build the project in this folder.

Generate the Xcode project:

```sh
xcodegen
```

Then open `AppCurtainExample.xcodeproj` in Xcode.

Files:
- AppCurtainExampleApp.swift
- AppDelegate.swift
- ContentView.swift
- project.yml
